## Recruit Desk 0.1.6

### What changed
- **Windows installer:** the Node.js step no longer tells you to run `winget`. The "Install Node.js LTS" button already falls back to the official installer from nodejs.org when winget is missing; the hand-run hint on that page now says to download the LTS installer from https://nodejs.org, run it, and press "Check again". This fixes the "winget not found" message on PCs without winget.
- **Releases:** this version is built and published by the GitHub Actions workflow, not on a laptop. The installer is the same product; nothing in the app itself changed.

### Install and update
- **Windows:** run `Recruit-Desk_0.1.6_x64-setup.exe`. Installed copies update themselves from this release.
- **Linux:** `sudo apt install ./Recruit-Desk_0.1.6_amd64.deb`. There is no in-app update on Linux.
- See `INSTALL.md` for the full guide.

### Known limitations
- The Windows installer is not code-signed yet, so your browser and Windows may warn ("isn't commonly downloaded", "Unknown publisher"). Choose Keep, then More info, then Run anyway. Download only from this page.
