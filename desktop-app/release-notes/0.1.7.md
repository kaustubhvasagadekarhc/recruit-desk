## Recruit Desk 0.1.7

### What changed
- **The Excel file is created for you.** The Windows installer now creates each assistant's empty Excel file in `Documents\RecruitDesk-Data` (`Find candidates`, `Company jobs` and `Accounts`), with its sheets and headers. Every assistant also checks at the start of each run and creates the file if it is missing, which covers Linux and any file you deleted. A file that already exists is never touched, so your results are safe.
- **Company jobs, no roles found.** A scan that finds no open roles (for example a small company with no careers page) is no longer reported as a failed step. The Excel file is still created if it was missing, and the run ends with a clear "no roles found" result.
- **Records are added and updated in that file.** Later runs add new rows and update the existing ones in the same file, as before.

### Install and update
- **Windows:** run `Recruit-Desk_0.1.7_x64-setup.exe`. Installed copies update themselves from this release, and the update copies the new assistant code over the old, then each assistant creates its Excel file on its next run.
- **Linux:** `sudo apt install ./Recruit-Desk_0.1.7_amd64.deb`. There is no in-app update on Linux. The Excel files are created on the first run.
- See `INSTALL.md` for the full guide.

### Known limitations
- The Windows installer is not code-signed yet, so your browser and Windows may warn ("isn't commonly downloaded", "Unknown publisher"). Choose Keep, then More info, then Run anyway. Download only from this page.
