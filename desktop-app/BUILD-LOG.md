  1. Welcome
  2. Step 1 of 4: Node.js and npm — checks `node -v` and `npm -v`; "Install Node.js LTS" runs `winget install -e --id OpenJS.NodeJS.LTS`, or downloads the newest LTS MSI listed in nodejs.org/dist/index.json and runs it (`/passive`; Windows shows its own admin prompt for that MSI only).

## 0.5.6: usage window starts with the first token (2026-10-15, god)

- Human rule: the 4-hour timer starts when token usage begins, not when the allowance hits 100%.
- cap.rs:
  - A new `window_started` field opens on the first token used. The window accrues time on the same high-water clock, so it is still safe against a clock set backwards.

## 0.8.0: sign-in (2026-10-18)

The network (ureq with rustls, no redirects, 8 s connect and 15 s total timeouts), the OS keychain (keyring: Windows Credential Manager, Linux Secret Service, macOS Keychain) and auth.json sit behind small traits, so the flow is tested with fakes. It verifies the server's Ed25519 access tokens itself (ed25519-dalek: algorithm EdDSA only, issuer and audience checked, `none` and HS256 refused).
