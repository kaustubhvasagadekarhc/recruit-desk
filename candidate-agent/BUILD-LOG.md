- `excel_upsert.py` now also appends every NEW row of an upsert (not only the newest) to `new_rows.jsonl` in this folder: one JSON line each, the same fixed field list as `last_record.json`, the key only as a sha256 hash, no email, phone, evidence or notes, no network. Recruit Desk stores those rows in its person's search history and removes what it stored. The file stops growing past 4 MB and is git-ignored and never packed into the installer. `memory.py forget` also removes that person's queued rows (`new_rows.jsonl` and the app's working copy `new_rows.sending.jsonl`) and appends a tombstone per key to `erased_rows.jsonl`, so the app removes any copy it already stored (the forget report gains `history_rows_removed`).
